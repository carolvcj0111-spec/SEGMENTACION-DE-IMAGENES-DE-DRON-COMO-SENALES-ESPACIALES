# SEGMENTACION-DE-IMAGENES-DE-DRON-COMO-SENALES-ESPACIALES

Este proyecto busca aplicar conceptos de procesamiento digital de señales al
análisis y segmentación de imágenes capturadas con dron en el campus de la Universidad del
Magdalena. El reto consiste en seleccionar un conjunto de imágenes RGB o multiespectrales y
desarrollar un flujo reproducible para separar regiones de interés, estimar áreas o contar objetos a
partir de la información espacial presente en las imágenes.
